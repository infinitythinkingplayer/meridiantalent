# meridiantalent.au

Single-page site for MERIDIAN TALENT PTY LTD (ACN 701 340 409).

## How to edit the text

1. Go to **https://pagescms.org** and sign in with GitHub.
2. Open this repository, then **网站文案 Website copy**.
3. Every line has a 中文 box and an English box. Edit the text, click Save.
4. GitHub Pages rebuilds automatically; the change is live in about a minute.

Only edit the text inside the boxes. Do not rename keys or change the
structure — `index.html` refers to each key by name.

## Files

| File | What it is |
|---|---|
| `index.html` | The page template. Markup, CSS and JS. No copy. |
| `_data/content.yml` | All the copy, Chinese and English. This is what the CMS edits. |
| `.pages.yml` | Pages CMS form configuration (field labels). |
| `_config.yml` | Jekyll build settings. |
| `CNAME` | Custom domain. |
